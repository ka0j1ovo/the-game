# The Game · 黄狗国赛事数据中心

一个类似 Liquidpedia 的赛事数据记录工具。纯前端单页应用，**无需服务器、无需安装**，
数据全部保存在浏览器 `localStorage` 中，可导出 / 导入 `esports-data.json`。

## 如何打开

双击 `index.html` 用浏览器打开即可（推荐 Chrome / Edge）。
首次打开为空数据，可点击首页或页脚的 **「载入示例数据」** 熟悉全部功能。

> 提示：请固定使用同一个浏览器打开，数据按浏览器隔离存储。

## 功能总览

- **俱乐部管理**：新建「HUPL席位队伍 / 次级队伍 / 外赛区队伍」，可设固定/临时席位、外赛区归类
  （HO红狗国 / CH橙狗 / LV绿狗 / OP剩余赛区 / GP粉金赛区）、队伍颜色与备注。
- **赛年**：新建赛年，赛年内集中查看该年全部赛事；赛年自带 **HUPL 积分表**
  （队伍 × 各分站积分，自动求和、自动排名）。
- **赛事**：新建空白赛事，选择分类（次级赛事 / HUPL / 国际赛事）与子类型
  （A-League、晋升赛、HUDL、National、the Cup、League Cup、Clash、Series、World Championship…），
  多选赛制（小组赛 / 瑞士轮 / 单败 / 双败），按选择顺序生成「阶段」框架。
  - 小组赛：可编辑小组、自动分组、生成小组内单循环对阵；
  - 瑞士轮：设置轮数，生成首轮对阵；
  - 单败 / 双败：生成首轮对阵，双败可标注胜者组/败者组；
  - 每个阶段可填对局比分、胜者、阶段名次；赛事可填「最终名次」表。
  - HUDL 赛事自带「分站积分表」，也可为任意赛事启用积分表。
- **队伍档案**：查看队伍历届参赛成绩（含名次）与对阵成绩（Head-to-Head 胜/负）。
- **搜索**：顶栏搜索框实时检索比赛 / 队伍。
- **数据管理**：一键导出 `esports-data.json`、导入 JSON（覆盖前确认）、清空（二次确认）、
  任何修改自动持久化到 localStorage。

## 目录结构

```
TheGame/
├── index.html      # 页面结构与弹窗
├── css/style.css   # Liquidpedia 风格样式（深蓝 + 白，表格为核心）
└── js/app.js       # 全部逻辑（数据层 + 渲染 + 交互）
```

## 数据备份建议

数据只存在浏览器里，**请定期点击右上角「导出」下载 `esports-data.json` 备份**，
换浏览器或清理浏览器缓存前务必先导出。
